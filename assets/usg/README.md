# Gambar USG asli untuk Atlas SIJ

Taruh tangkapan layar USG (sudah dianonimkan) di folder ini dengan nama sesuai kode titik:

| File | Titik |
|---|---|
| `IA.jpg` / `.png` | Intra-artikular SIJ (transversal, S3–S4) |
| `PA.jpg` | Periartikular SIJ superior (transversal, S1/PSIS) |
| `LDL.jpg` | Ligamen sakroiliaka dorsal panjang (longitudinal-oblik) |
| `LB.jpg` | Cabang lateral S1–S3 (transversal, foramen S2) |
| `L5.jpg` | Ramus dorsalis L5 (transversal, L5–S1) |

Tab "🦴 Atlas SIJ" otomatis menampilkannya di mode **USG asli**.
Pastikan tidak ada identitas pasien (nama, No. RM, tanggal lahir) pada gambar.
